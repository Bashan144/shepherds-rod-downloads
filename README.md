# The Shepherd’s Rod (Bashan) — Windows downloads

Official Windows installers and update information. This repository distributes the app; the application source and signing keys are not published here.

## Install or update

1. Open [Releases](https://github.com/Bashan144/shepherds-rod-downloads/releases) and download the latest `ShepherdsRod-…-Setup.exe` installer.
2. Close The Shepherd’s Rod before installing.
3. Run setup and update the existing installation using the same Windows account and installation folder. Do not uninstall or clear app data.

Starting with Windows 0.3.72, the app can check for new versions at startup and daily while it is running. Failed checks retry quietly. A notification offers View update, Later, Remind me tomorrow and Skip this version. Downloading and opening setup require your choice. Settings → App updates also provides manual checking and an automatic-check switch. No updater service runs when the app is closed.

The Tract 6 quiz, quiz and reading progress, bookmarks, highlights, audiobook listening positions and downloaded audiobooks remain in the existing Windows user profile. The installer replaces program files only.

The updater verifies the download size and SHA-256 checksum before opening setup. Release checksums are attached to each release. Older Windows builds require one manual installation to enable the integrated updater.
